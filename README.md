# HotelFlow — исходный код прототипа

Автор: Уразбаев Али. Дипломный проект информационной системы управления гостиничным комплексом.

## Состав
- Гостевой интерфейс: меню, корзина, заказ в номер и заявки на обслуживание.
- Администратор: управление номерами, доступами, меню, журналом операций.
- Сотрудники: уборка, кухня, бар, доставка и ресепшен.
- Красный статус — нужна уборка, зелёный — убрано, жёлтый — активный заказ.
- Серверное сохранение данных и проверка ролевых прав.

## Основные файлы
- app/page.tsx — интерфейсы и взаимодействия.
- app/globals.css — оформление и адаптация под телефон.
- app/api/hotel/route.ts — серверная логика, роли и заказы.
- app/chatgpt-auth.ts — вход через ChatGPT.
- db/schema.ts и drizzle/ — схема базы и SQL-миграции.
- package.json — зависимости и команды.

## Локальный запуск (Windows / macOS / Linux)
Требуется Node.js версии 22.13.0 или выше и pnpm 11.25.0.
Откройте терминал в папке HotelFlow и выполните:

```sh
pnpm install
pnpm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_white_prima.sql
pnpm run dev
```

Откройте адрес из терминала (обычно http://localhost:5173).
При первом входе нажмите «Войти». В локальном режиме на loopback-адресе используется демонстрационная авторизация стартового проекта. Первый вошедший пользователь инициализирует отель и становится владельцем.
Миграция выполняется однократно для новой локальной базы. При повторном запуске достаточно `pnpm run dev`.

## Загрузка как прототип
Архив содержит исходный проект, а не только HTML. Для импорта платформа должна поддерживать React/TypeScript, Vinext и Cloudflare Workers/D1. Для передачи преподавателю или добавления к репозиторию загрузите весь архив.
Это не одиночный HTML-файл; двойной щелчок по page.tsx не запускает сайт.
Данная версия использует D1, а не PostgreSQL. При переносе на обычный Node.js-хостинг нужно адаптировать базу и авторизацию.

## Демонстрация
Вверху интерфейса владелец может выбрать роль. Проверьте цепочку: гость → меню → заказ → повар/бармен → официант → доставка. Проверьте запрос уборки и изменение цвета номера.
Демонстрационные данные создаются при первом входе. Локальная база хранится в .wrangler/state, в архив она не включена.

## Границы версии
Это прототип. Онлайн-оплата, бронирование по датам и отдельная авторизация гостей гостиницы не реализованы. Научные результаты необходимо получить отдельным экспериментом.
Сборка и проверки TypeScript были выполнены при создании сайта. Серверные сценарии проверены с имитацией базы и пользователя; визуальная проверка в браузере не выполнена. Архив локально на Windows не проверялся.

Исходная опубликованная демонстрация: https://hotelflow.regalcrane8.chatgpt.site
